## 🔬 Research

### WaveFormer-Net

**Cross-Frequency Wavelet and Offset-Guided Upsampling for Tiny Retinal Vessel Segmentation**

My current research focuses on retinal vessel segmentation, with an emphasis on preserving tiny-vessel structures through frequency-aware feature processing and dynamic upsampling.

The project explores:

`Wavelet Decomposition` → `Frequency Interaction` → `Attention` → `Dynamic Upsampling`

📊 Evaluated on:

`DRIVE` · `STARE` · `CHASE_DB1`
